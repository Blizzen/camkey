# CamKey

Camera keyframe and playback tool for Minecraft 1.21.1 (NeoForge).

Capture named camera positions in-game, then play them back as one smooth,
eased camera move: the kind of tool you would use to set up a cinematic shot
for a recording session.

**Status: work in progress.** Full README (usage, architecture decisions,
limitations, AI-usage notes) lands with the first complete version.

## Build

```
./gradlew build
```

Jar lands in `build/libs/`. Requires Java 21.

## Run in dev

```
./gradlew runClient
```
